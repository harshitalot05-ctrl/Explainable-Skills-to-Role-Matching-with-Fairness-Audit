# Explainable Skills-to-Role Matching with Fairness Audit

A BSc Data Science project that analyzes a resume, extracts skills, matches them with suitable job roles, explains the matching result, and performs a basic fairness audit.

## Technologies Used

- Python
- Streamlit
- Pandas
- spaCy
- Plotly

## Main Features

- Resume upload
- Skill extraction
- Role matching
- Match percentage
- Matched and missing skills
- Fairness audit
- Visual results

## How to Run

```bash
py -m streamlit run app.py
